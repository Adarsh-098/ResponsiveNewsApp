Assignment Report: Responsive Design Using React Native

1. Objective

To develop a responsive mobile application using React Native and understand Flexbox layouts, screen dimensions, and adaptive user interfaces.

2. Tools and Technologies
   Visual Studio Code
   React Native
   Expo
   JavaScript/TypeScript
   Git and GitHub
3. Project Description

A responsive News App was developed using React Native. The application displays news cards containing categories, headlines, descriptions, and read-more labels. The interface adapts to different screen sizes and orientations.

4. Implementation

The application uses Flexbox properties such as flex, flexDirection, flexWrap, justifyContent, and alignItems to arrange its components. The useWindowDimensions() hook detects screen dimensions and adjusts the layout between one-column and two-column arrangements.

5. Result

The application was designed to support portrait and landscape orientations and different screen widths. The responsive layout improves readability and makes better use of the available screen space.

6. Conclusion

This assignment provided practical experience in creating responsive layouts with React Native. It demonstrated how Flexbox and screen dimensions can be used to build adaptable mobile interfaces. The source code was prepared for version control and submission through GitHub.
